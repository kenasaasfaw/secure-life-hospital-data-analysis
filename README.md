# Secure Life General Hospital – Data Analysis

## Project Overview

This project focuses on analyzing patient admission, billing, payment, and insurance data for Secure Life General Hospital.

The objective is to transform raw hospital data into meaningful insights through data analysis and interactive dashboard development to support management decision-making.

## Business Problem

Hospital management needs a consolidated reporting system to monitor patient admissions, departmental performance, outstanding medical bills, insurance coverage, and financial operations.

This project addresses these challenges through data cleaning, exploratory data analysis, visualization, and business intelligence reporting.

## Project Objectives

1. Analyze the total number of patient visits.
2. Identify departments with the highest patient volume.
3. Determine departments generating the highest total bills.
4. Evaluate average patient length of stay across departments.
5. Analyze payment status distribution.
6. Calculate total billing and outstanding balances.
7. Examine insurance coverage across departments and diagnoses.
8. Identify the age groups with the highest patient visits.
9. Analyze monthly admission and billing trends.
10. Identify operational and financial areas requiring management attention.

## Dataset Description

The dataset contains hospital patient visit records with the following attributes:

- Patient ID
- Patient Name
- Age
- Gender
- Admission Date
- Discharge Date
- Department
- Diagnosis
- Total Bill Amount
- Insurance Coverage (%)
- Payment Status

**Important:** Each row represents one patient visit, not necessarily one unique patient.

The analysis examines:

- Departmental patient demand.

## Management Recommendations

- Strengthen payment collection and follow-up processes.
- Monitor departments with high outstanding balances.
- Review insurance coverage variations.
- Improve resource planning based on patient admission trends.
- Monitor departments with longer average patient stays.
